车计隐私政策

更新日期：2026年5月30日 ｜ 生效日期：2026年5月30日

车计重视你的隐私。本政策说明本应用会在你的设备上使用哪些数据，以及我们如何处理这些数据。 车计的核心设计原则是：本地保存、用户自主管理、不采集、不上传用户车辆记录。

一、我们不会做什么

  1. 我们不会注册账号，也不会要求你提供手机号、邮箱、姓名、身份证号等身份信息。
  2. 我们不会将你的车辆信息、费用记录、里程、油耗、电耗、备份内容上传到我们的服务器。
  3. 我们不会采集你的通讯录、短信、照片、麦克风、摄像头等与记账无关的信息；精确定位只会在你主动点击记录表单中的定位图标并授权后，用于辅助填写该条记录的地点。
  4. 我们不会出售、出租或向第三方提供你的个人数据。
  5. 我们不会使用第三方广告 SDK 追踪你的使用行为。
  6. 普通本地记账、统计和查看历史记录无需网络请求。

二、本应用会在本地使用的数据

  1. 车辆信息：车辆名称、品牌、型号、能源类型、车牌号、里程、容量、购车日期、残值、车辆照片等。
  2. 记录信息：加油、充电、停车、保险、保养、维修、洗车、过路费、违章、购车款等费用记录。
  3. 能耗与里程数据：加油量、充电量、SOC、里程表读数、费用金额、记录日期、备注等。
  4. 地点信息：你手工填写的地点名称，或你主动授权定位后由系统定位、地址反查和附近地点搜索返回的地址、地点名称、经纬度和地点来源。地点字段为可选项，不填写不影响基础记账和统计。
  5. 统计数据：本月支出、总成本、每公里成本、平均油耗、电耗、年度报告、成本趋势等。
  6. 备份与同步配置：本地备份状态、备份文件信息、云同步类型、WebDAV 地址、同步状态等。
  7. 安全设置：主密码状态、生物识别开关、本地加密相关状态。主密码不会上传给我们。
  8. 购买与权益状态：应用可能会读取必要的 Pro 权益状态，用于决定是否开放对应功能。

三、系统权限说明

  1. 文件访问：用于选择备份文件、保存导出文件、恢复备份或分享导出文件。
  2. 生物识别：如果你启用指纹或面容解锁，本应用只调用系统验证结果，不会获取或保存你的生物特征数据。
  3. 定位权限：仅在你点击加油、充电或支出表单中的定位图标时请求，用于获取当前位置、反查地址并搜索 200 米以内的附近地点候选。你可以拒绝授权，拒绝后仍可手工输入地点并继续使用基础记录功能。
  4. 网络访问：仅在你主动配置云同步、使用需要网络的云盘/WebDAV 功能、购买或恢复 Pro 权益、检查商店权益状态，或系统定位/地图服务为完成地址反查和附近地点搜索而需要网络时使用。普通本地记账和统计无需网络请求。

四、地点信息的使用边界

  1. 地点信息用于帮助你补全加油、充电、停车、维修、洗车等记录的发生地点，并用于后续地点相关统计、搜索、导出或年度报告展示。
  2. 当前 iOS 版本使用系统定位、CLGeocoder 地址反查和 MapKit 附近地点搜索能力。地点候选默认限制在当前位置 200 米以内，并按距离排序展示。
  3. 地址和附近地点候选可能存在误差，你可以在选择后自行修改地点名称，也可以完全手工填写。
  4. 地点信息默认保存在本机数据库中。如果你主动导出 CSV/XLSX、导出加密备份、恢复备份或启用云同步，地点字段会随记录数据一并导出、备份、恢复或同步。
  5. 云同步目标由你自己配置和管理，例如 OneDrive、iCloud、WebDAV 或其他支持的存储空间；同步数据保存到你自己的云盘或服务器，不会上传到车计自建服务器。
  6. 你可以通过编辑记录修改地点信息，也可以通过删除记录删除对应地点数据。

五、云同步与备份

  1. 云同步是可选功能。只有你主动配置并启用后，应用才会同步加密后的备份数据。
  2. 云同步目标由你提供和管理，例如 OneDrive、iCloud、WebDAV 或其他支持的存储空间。
  3. 你可以随时停止使用云同步，或删除个人云盘中的备份文件。
  4. 云同步属于 Pro 功能。若 Pro 权益不可用，自动云同步可能暂停。
  5. 备份密码、主密码和云盘账号应由你妥善保管。若忘记密码，已加密的备份将无法恢复。

六、购买与 Pro 权益

  1. 在应用商店版本中，订阅、买断、续费、取消、退款和恢复购买由对应应用商店处理。
  2. 应用只读取 Pro 权益是否有效，用于开放或限制相关功能。我们不会获取你的完整银行卡号或支付密码。

七、数据删除与导出

  1. 你可以在应用内删除车辆或记录。部分删除内容可能先进入回收站，具体以应用功能为准。
  2. 你可以主动导出加密备份或全量数据文件，用于迁移、留档或自行保存。
  3. 卸载应用、清除应用数据、删除备份文件或删除云盘文件，可能导致数据永久丢失。

八、未成年人

本应用面向具备车辆或费用管理需求的用户，不专门面向未成年人。如果未成年人使用本应用，应在监护人指导下进行。

九、政策更新

如果应用功能发生变化，隐私政策可能同步更新。你继续使用本应用，视为接受更新后的隐私政策。

十、联系我们

如你对隐私保护或数据处理方式有疑问，可通过应用内“关于”页面显示的联系方式与我们联系。
